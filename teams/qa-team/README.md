# QA team

Independent testing: strategy, automation, exploration, accessibility and performance.

The QA team tests independently of the people who built the change. Rita (QA Lead) takes requests from the Product squad, plans the testing and gives the release verdict. Oscar automates, Esther explores, Ari covers accessibility and performance. Bugs go back to whoever asked, with exact repro steps. The team never changes production data or ships anything itself.

## Members

- **Rita**, QA Lead (Lead): Plans testing by risk and gives the release verdict. Skills: `test-strategy-and-regression-plan`, `release-signoff`, `bug-report`.
- **Oscar**, Test Automation Engineer: Writes reliable unit, integration and end-to-end tests. Skills: `playwright-e2e-tests`, `unit-and-integration-test-design`, `test-driven-development`, `systematic-debugging`.
- **Esther**, Exploratory Tester: Runs exploratory sessions and writes bug reports anyone can reproduce. Skills: `exploratory-test-charters`, `bug-report`, `story-test-design`.
- **Ari**, Accessibility & Performance Tester: Checks WCAG accessibility and page performance. Skills: `web-accessibility-audit`, `web-performance-core-web-vitals`, `bug-report`.

## What you get

- A risk-based test plan and a clear ship / don't-ship verdict for each release.

Every bot starts on Ask. Skills from a shared team arrive switched off; switch them on in each bot's Skills. Rita is the team's Lead.
